# License review of PlanetTools.jl

Date: 2026-10-24; updated 2026-10-25 after moving the Makie-based code to a package extension, and again on 2026-10-25 after raising the minimum Julia version to 1.13.
Scope: PlanetTools.jl (MIT) with all direct, transitive, extension (weak), and test dependencies, including the compiled binary libraries ("artifacts") downloaded by `_jll` packages.
Platforms: x86_64 Linux, aarch64 macOS (Apple Silicon), and x86_64 Windows, Julia 1.13.2 (the minimum supported version); the macOS and Windows artifacts were downloaded and audited with `LICENSE_CHECK_PLATFORM`. CI runs the check on all three with the same Julia version.
The full inventory for Linux (371 entries; 356 for macOS, 353 for Windows) is in [`THIRD_PARTY_LICENSES.md`](../THIRD_PARTY_LICENSES.md); it is generated by [`scripts/license_check.jl`](../scripts/license_check.jl).
The inventory depends on the Julia version and on the dependency versions the resolver picks, so regenerate it whenever either changes.

This review is technical, not legal advice.

## Result

1. **Licensing PlanetTools under MIT is compatible with all its dependencies.**
   No dependency imposes its license on PlanetTools' own source code, because PlanetTools does not contain or redistribute third-party code; it only declares dependencies, which Pkg downloads separately under their own licenses. (Interpretation; confidence high.)
2. **All Julia code in the dependency tree is permissively licensed.** 151 Julia packages and 85 `_jll` wrapper packages (Linux): 139 MIT, 3 Apache-2.0, 2 Unlicense, and Zlib, BSL-1.0, BSD-2-Clause, CC0-1.0 combinations. (Verified from the license files.)
3. **The core package has one copyleft component: libiconv (LGPL), via NCDatasets → NetCDF → libxml2.**
   Its runtime dependencies are 131 entries on Linux, 45 of them Julia standard libraries. (Verified.)
   Since version 2, the HDF5 library (via NetCDF) also brings Amazon's AWS C libraries and the s2n-tls library, all Apache-2.0. (Verified from the license files in the artifacts.)
   On Windows only, NetCDF's HDF5 library also brings Microsoft MPI, a proprietary binary under Microsoft's Redistributable EULA, which permits redistribution under its conditions. (Verified from the EULA files in the artifact.)
4. **The other copyleft and non-free binaries belong to the optional Makie extension.**
   They are only installed and loaded when the user also uses Makie.
   The GPL libraries are FFmpeg, x264, x265, and Rmath.
   The LGPL libraries are GLib, FriBidi, LAME, Cairo (LGPL or MPL), libmount, gettext's libintl, and CRlibm.
   The FFmpeg binary is built with non-free components and states that it is not legally redistributable. (Verified.)
5. **Obligations arise only when someone redistributes the binaries.** Examples are a sysimage or app built with PackageCompiler, a Docker or Apptainer image, or an HPC software module that includes the Julia depot. (Interpretation; confidence high.)

## Method

1. PlanetTools was resolved in a fresh environment together with its weak dependencies (`[weakdeps]`) and test dependencies (`[extras]`), which are reported as separate scopes.
2. Each Julia package's license file was identified with LicenseCheck.jl, which matches license texts against the SPDX license list.
3. For each `_jll` package, the artifact for this platform was located, and every file in its `share/licenses/` directory was identified the same way.
4. Every entry not clearly permissive was read manually and, where the shipped license text was ambiguous, checked against the upstream project (sources below). The findings are recorded in the script, so that a new unreviewed license makes it fail.
5. The dependency path of every flagged library was traced back to PlanetTools' direct dependencies.

## Assessment

**PlanetTools' own license (interpretation; confidence high).**
The MIT ("Expat") license is a permissive license that the Free Software Foundation lists as compatible with the GPL [1].
A distributed work that combines MIT code with a GPL library must, as a whole, be licensed under the GPL, while the MIT-licensed modules keep their license [2].
PlanetTools does not distribute such a combination; its users' package manager assembles it locally.
Makie itself is MIT-licensed while depending on the same libraries, which is common practice in the Julia ecosystem.

**AI-assisted code (verified for the stated terms).**
Under Anthropic's Consumer Terms (effective 2025-10-08, section 4), "we assign to you all of our right, title, and interest—if any—in Outputs" [3]; the outputs carry no license conditions. If you use Claude through an organization plan, check its commercial terms. The code written in this project is original; it implements formulas from the cited papers but copies no third-party code.

**Redistribution of binaries (interpretation; confidence high).**
If PlanetTools is ever shipped with its dependencies (sysimage, container, app):
- the GPL and LGPL libraries require their license texts and access to their source code;
- the permissive and Apache-2.0 components require their copyright notices;
- the bundled FFmpeg must not be redistributed, by its own statement; FFmpeg's legal guidance is to build without `--enable-gpl` and `--enable-nonfree` for redistribution [4].

## Recommendations

1. **Plotting code in a package extension (done 2026-10-25).**
   `Makie`, `ColorSchemes`, and `Contour` are `[weakdeps]`; `compose_palette` and `finite_contour!` are implemented in `ext/PlanetToolsMakieExt.jl`, which loads once Makie is loaded [5].
   Redistributing the core package's binaries now involves only permissive libraries and the LGPL libiconv.
2. Keep [`THIRD_PARTY_LICENSES.md`](../THIRD_PARTY_LICENSES.md) in the repository and rerun `julia scripts/license_check.jl` when dependencies change, or in CI. The script exits with an error for any new license that is not clearly permissive and not yet reviewed.
3. The CI job `licenses` runs the check on Linux, macOS, and Windows, because artifacts are built per platform and may contain different libraries. Its Julia version is pinned to the minimum supported version (`1.13`), so that its inventory matches the committed one; raise it together with the `julia` compat entry and regenerate the inventory.
4. When building redistributable bundles, collect the `share/licenses` directories of all artifacts and leave out FFMPEG_jll.
