PlanetTools.Constructors — Module
PlanetTools.Constructors

Submodule of PlanetTools with utility constructors for ModelE / ROCKE-3D post-processing and plotting: fnames_modele builds monthly output file names and compose_palette builds discrete color palettes for binned plots. Load it with using PlanetTools.Constructors. compose_palette is defined in a package extension that is loaded once Makie is loaded (using Makie, using CairoMakie, …).

PlanetTools.Constructors.compose_palette — Function
compose_palette(breaks; kwargs...) -> Vector{Makie.RGBAf}

Return one color per interval between consecutive breaks (length(breaks) - 1 colors) for discrete contour or binned plots, built from one or two color schemes and an optional midcolor. Requires Makie to be loaded.

With both palettes, the intervals at or below demarcation take palette1, the interval from the last break ≤ demarcation to the next break takes midcolor (or else palette2), and the intervals above take palette2. If that interval does not exist, midcolor is not used and a warning is issued. With one palette, midcolor takes the top interval (palette1) or the bottom interval (palette2). Each palette is sampled evenly from its first to its last color; a single sample is its midpoint.

Use contourf(x, y, z; levels=breaks, colormap=pal). For extension bands pass extendlow=first(pal), extendhigh=last(pal); :auto makes Makie resample the colormap.

Arguments

  • breaks::AbstractVector{<:Real}: finite, strictly increasing, at least two values.

Keywords

  • palette1=nothing: lower palette, a ColorScheme or its name as Symbol/String.
  • midcolor=nothing: any color accepted by Makie.to_color, e.g. :white.
  • palette2=nothing: upper palette, same types as palette1.
  • demarcation::Real=1.0: value separating the palettes; used only if both are given.

Returns

  • Vector{Makie.RGBAf}: colors from the lowest to the highest interval.

Throws

  • ArgumentError: if breaks is invalid, no palette is given, or a scheme name is unknown.

See also fnames_modele.

Examples

julia> pal = compose_palette(
           [-2, -1, -0.5, 0.5, 1, 2];
           palette1=reverse(colorschemes[:Blues]),
           midcolor=:white,
           palette2=:Reds,
           demarcation=0,
       );

julia> length(pal), pal[3] == Makie.to_color(:white)
(5, true)

PlanetTools.Constructors.fnames_modele — Method
fnames_modele(fyear, fmonth, lyear, lmonth, gname, ids; ext=".nc") -> Matrix{String}

Build ModelE / ROCKE-3D monthly output file names "<MON><YYYY>.<gname><id><ext>", e.g. "JAN1950.aijE001.nc", for each run ID in ids and each month from fyear-fmonth to lyear-lmonth (inclusive). <MON> is the upper-case English month abbreviation (locale-independent) and <YYYY> the year zero-padded to four digits.

Arguments

  • fyear::Integer: first year, ≥ 0.
  • fmonth::Integer: first month, 1:12.
  • lyear::Integer: last year, ≥ 0.
  • lmonth::Integer: last month, 1:12.
  • gname::AbstractString: diagnostic file group, e.g. "aij" or "taij".
  • ids::AbstractVector{<:AbstractString}: run IDs.

Keywords

  • ext::AbstractString=".nc": file extension; "" for none.

Returns

  • Matrix{String}: size (length(ids), nmonths); rows are runs, columns are months in chronological order.

Throws

  • ArgumentError: if a month is outside 1:12, a year is negative, the start date is after the end date, or ids is empty.

See also compose_palette.

Examples

julia> fnames_modele(1950, 12, 1951, 1, "aij", ["E001", "E002"])
2×2 Matrix{String}:
 "DEC1950.aijE001.nc"  "JAN1951.aijE001.nc"
 "DEC1950.aijE002.nc"  "JAN1951.aijE002.nc"
