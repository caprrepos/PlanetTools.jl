PlanetTools.ReadWritePlanet — Module
PlanetTools.ReadWritePlanet

Submodule of PlanetTools for reading and writing NetCDF files of planetary model output with NCDatasets.jl: writenetcdf writes variables with coordinates and metadata, readnetcdf reads selected variables and their metadata. Load it with using PlanetTools.ReadWritePlanet.

source
PlanetTools.ReadWritePlanet.readnetcdf — Method
readnetcdf(filepath, var_names; missing_as_nan=false) -> NamedTuple

Read the global attributes and the selected variables of a NetCDF file, with their metadata. Values are read as NCDatasets returns them: scale factors and offsets are applied, and values equal to _FillValue become missing. Requested variables that do not exist are skipped with a warning.

Arguments

  • filepath::AbstractString: path of the NetCDF file.
  • var_names::AbstractVector{<:AbstractString}: names of the variables to read.

Keywords

  • missing_as_nan::Bool=false: return floating-point data with NaN instead of missing (element type without Missing), as expected by PlanetTools' statistics.

Returns

  • NamedTuple with fields
    • global_attributes::OrderedDict{String,Any}: global attributes;
    • variable_info::OrderedDict{String,Any}: per variable, a dictionary with "name", "dimensions" (tuple of names), "dimension_sizes", and "attributes";
    • variable_data::OrderedDict{String,Any}: per variable, its data as an Array.

See also writenetcdf.

Examples

julia> path = joinpath(mktempdir(), "example.nc");

julia> x = [1.0 NaN; 3.0 4.0];

julia> writenetcdf(path; data=x, names="x", dataattr=Dict("_FillValue" => -999.0));

julia> eltype(readnetcdf(path, ["x"]).variable_data["x"])
Union{Missing, Float64}

julia> isnan(readnetcdf(path, ["x"]; missing_as_nan=true).variable_data["x"][1, 2])
true

PlanetTools.ReadWritePlanet.writenetcdf — Method
writenetcdf(path; kwargs...) -> Nothing

Write one or several variables, their coordinates, and metadata to the NetCDF file path.

Dimension i is named dimnames[i] (default "dimension<i>"). If a coordinate datadim<i> is given, the dimension gets its length and a coordinate variable of the same name; a dimension named "time" is unlimited. Dimensions without coordinates are created from the size of the data. Existing dimensions and variables (e.g. with mode="a") are kept; a variable that already exists is not overwritten.

Keywords

  • data=nothing: a scalar, an array for one variable, or for several variables an array whose first dimension indexes names, [Var, Lon, Lat, …].
  • names=nothing: variable name (AbstractString) or vector of names.
  • dimnames=nothing: dimension names of the variables (without the Var dimension).
  • datadim1, …, datadim6: coordinates of dimensions 1 to 6; dim1attr, …, dim6attr: their attributes (e.g. Dict("units" => "degrees_east")).
  • dataattr=nothing: attributes of the variable, or a vector with one dictionary per name.
  • vtype=nothing: element type to convert data and axypvar to, e.g. Float32.
  • datevar=nothing: dates written as strings to variable "Dates" along the "time" dimension (or the last dimension); datevarattr: its attributes.
  • axypvar=nothing: cell areas (Lon, Lat) (or (Lat,)) written to variable "axyp" on the first two dimensions (default "lon", "lat"); axypvarattr: its attributes.
  • globalattr=nothing: global attributes, any collection of name–value pairs.
  • mode::AbstractString="c": "c" creates (overwrites) the file, "a" appends.
  • format::Symbol=:netcdf4: file format, see NCDatasets.NCDataset.

Throws

  • ArgumentError: if the sizes of data, names, dimnames, the coordinates, or dataattr do not agree. The inputs are checked before the file is opened.

See also readnetcdf.

Examples

julia> path = joinpath(mktempdir(), "example.nc");

julia> u = reshape(Float32.(1:6), 3, 2);  # (lon, lat)

julia> writenetcdf(path; data=u, names="u", dimnames=["lon", "lat"],
           datadim1=[0.0, 120.0, 240.0], datadim2=[-45.0, 45.0],
           dataattr=Dict("units" => "m s-1"), globalattr=Dict("title" => "test"));

julia> r = readnetcdf(path, ["u"]);

julia> r.variable_data["u"] == u, r.variable_info["u"]["dimensions"]
(true, ("lon", "lat"))
