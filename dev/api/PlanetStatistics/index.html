PlanetTools.PlanetStatistics — Module
PlanetTools.PlanetStatistics

Submodule of PlanetTools with statistics for gridded planetary model output: zonal and global means, annual and seasonal mean time series, multi-year statistics, anomalies, linear trends with significance, and ensemble statistics. Load it with using PlanetTools.PlanetStatistics.

Conventions shared by all functions:

  • Arrays are laid out as (Sim, Var, Lon, Lat, [Lev], Time); reduced dimensions are kept as singletons (e.g. zonal means (Sim, Var, 1, Lat, [Lev], Time)).
  • Missing data are NaN.
  • Optional availability weights (fractions in [0, 1], e.g. returned by an earlier step) multiply the temporal weights (e.g. days per month); points with weight 0 count as missing.
  • threshold is the minimum percentage of valid points for a result; otherwise the result is NaN and its availability weight 0.
  • Results are written into preallocated output arrays; entries not covered by a calculation are left unchanged, so initialize outputs with NaN.
  • Simulations are processed in parallel with Threads.@threads; within a simulation the output points are processed in parallel as well, so a single simulation also uses all threads.
  • The kernels are explicit loops that accumulate in Float64 and allocate no temporary arrays of the size of the data.
  • Standard deviations are sample standard deviations (corrected=true, Bessel's correction generalized to weights) unless corrected=false is passed.

PlanetTools.PlanetStatistics.calc_annual_mean_ts! — Method
calc_annual_mean_ts!(
    data, zm, gm, ann_out, zm_ann_out, gm_ann_out, ann_w_out, zm_ann_w_out,
    gm_ann_w_out, dates, t_ranges, full_year_dates; kwargs...
) -> Nothing

Compute weighted annual means of monthly grid-point, zonal-mean, and global-mean time series, with the fraction of valid months per year as availability.

Year ny of simulation ns averages the 12 months starting at the first date of full_year_dates[ns] plus ny - 1 years; years extending beyond t_ranges[ns] are skipped. Monthly weights are the availability weights times month_weights.

Arguments

  • data, zm, gm: monthly inputs, (Sim, Var, Lon, Lat, [Lev], Time) and the zonal and global reductions thereof.
  • ann_out, zm_ann_out, gm_ann_out: annual means, input shapes with Time replaced by Year.
  • ann_w_out, zm_ann_w_out, gm_ann_w_out: annual availability, same shapes.
  • dates::AbstractVector{<:Date}: dates of the Time dimension.
  • t_ranges::AbstractVector{<:Integer}: number of valid time steps of each simulation.
  • full_year_dates::AbstractVector: per simulation, a date range of the complete years to average (e.g. Date(1951):Year(1):Date(2000)); empty to skip a simulation.

Keywords

  • data_w=nothing, zm_w=nothing, gm_w=nothing: availability weights of the inputs.
  • month_weights=nothing: weights along Time, e.g. days per month; default equal.
  • threshold::Real=100.0: minimum percentage of valid months per year.
  • run_names=nothing, verbose::Bool=false: progress logging.

PlanetTools.PlanetStatistics.calc_anomalies! — Method
calc_anomalies!(anom_out, data, clim_mean, indices) -> Nothing

Compute anomalies from a monthly climatology: for each simulation ns and month m, anom_out[ns, …, t] = data[ns, …, t] - clim_mean[ns, …, m] for all t in indices[ns, m]. Time steps not listed in indices are left unchanged.

Arguments

  • anom_out: output, same size as data.
  • data::AbstractArray: (Sim, Var, …, Time).
  • clim_mean::AbstractArray: (Sim, Var, …, 12), e.g. from calc_multiyear_stats! with Val(:monthly).
  • indices::AbstractMatrix{<:AbstractVector}: (Sim, 12) time indices of each month.

PlanetTools.PlanetStatistics.calc_ensemble_agreement! — Method
calc_ensemble_agreement!(
    pos_count, neg_count, agreement_frac, moa; kwargs...
) -> Nothing

Count the simulations (dimension 1 of moa) with positive and negative values and compute the sign agreement max(pos, neg) / n_valid, from 0.5 (no consensus) to 1 (all agree). Valid members are non-NaN with weight > 0. Where fewer than threshold percent of the simulations are valid, counts are 0 and the agreement is NaN.

Arguments

  • pos_count, neg_count, agreement_frac: outputs, moa without dimension 1.
  • moa::AbstractArray: (Sim, Var, …), e.g. trends of each simulation.

Keywords

  • w_moa=nothing: availability weights, same size as moa.
  • threshold::Real=0.0: minimum percentage of valid simulations.

Examples

julia> moa = reshape([0.3, 0.1, -0.2, 0.4], 4, 1);

julia> p, n, a = zeros(Int, 1), zeros(Int, 1), fill(NaN, 1);

julia> calc_ensemble_agreement!(p, n, a, moa);

julia> p[1], n[1], a[1]
(3, 1, 0.75)

PlanetTools.PlanetStatistics.calc_ensemble_stats! — Method
calc_ensemble_stats!(ens_mean, ens_std, moa; kwargs...) -> Nothing

Compute the weighted ensemble mean and standard deviation over the simulations (dimension 1 of moa), and optionally skewness and excess kurtosis. The standard deviation is the sample standard deviation for reliability weights (corrected=true, see calc_multiyear_stats!) or the population standard deviation (corrected=false); skewness and kurtosis are population moments.

The ensemble availability is Σ w / n_sims over valid members, with w from w_moa (or 1); where it is below threshold percent, the results are NaN.

Arguments

  • ens_mean, ens_std: outputs, moa without dimension 1.
  • moa::AbstractArray: (Sim, Var, …), e.g. multi-year means of each simulation.

Keywords

  • ens_ska=nothing, ens_kua=nothing: outputs for skewness and excess kurtosis.
  • w_moa=nothing: availability weights, same size as moa.
  • threshold::Real=0.0: minimum ensemble availability in percent.
  • corrected::Bool=true: sample (true) or population (false) standard deviation.

Examples

julia> moa = reshape([1.0, 2.0, 6.0], 3, 1);  # 3 simulations, 1 variable

julia> m, s = fill(NaN, 1), fill(NaN, 1);

julia> calc_ensemble_stats!(m, s, moa);

julia> m[1], s[1] ≈ sqrt(14 / 2)
(3.0, true)

calc_linear_trends!(slopes, data, weights, dates) -> Nothing

Compute the weighted least-squares linear trend of each time series in data, in units of data per year. Time is the fractional year year + (month - 1) / 12 of dates.

At least two valid points (non-NaN, weight > 0) are required; otherwise the slope is NaN. The fit is done in Float64 with centered time.

julia> slopes = fill(NaN, 1, 1);

julia> calc_linear_trends!(slopes, data, nothing, dates);

PlanetTools.PlanetStatistics.calc_linear_trends_sig! — Method
calc_linear_trends_sig!(slopes, p_values, data, weights, dates; kwargs...) -> Nothing

Compute weighted least-squares linear trends as calc_linear_trends! and their two-sided p-values from a Student's t-test of zero slope with n - 2 degrees of freedom.

With autocorrelation=true, the sample size is reduced to the effective sample size n_e = n (1 - r₁) / (1 + r₁) (with n_e ≤ n), where r₁ is the lag-1 autocorrelation of the residuals in time order, following Santer et al. [2000]. Without it, autocorrelated series such as monthly anomalies get p-values that are too small.

At least three valid points are required (n_e > 2 with autocorrelation=true); otherwise slope and p-value are NaN.

Arguments

  • slopes, p_values: outputs, (Sim, Var, …).
  • data::AbstractArray: (Sim, Var, …, Time).
  • weights: weights, same size as data, or nothing for equal weights.
  • dates::AbstractVector{<:Date}: dates of the Time dimension.

Keywords

  • autocorrelation::Bool=false: correct for lag-1 autocorrelation of the residuals.

References

  • Santer, B. D., et al. (2000), Statistical significance of trends and trend differences in layer-average atmospheric temperature time series, J. Geophys. Res., 105(D6), 7337–7356, doi:10.1029/1999JD901105.

Examples

julia> dates = Date(2000, 1):Month(1):Date(2001, 8);

julia> data = reshape([0.1 * i + (-1)^i for i in 1:20], 1, 1, 20);

julia> slopes, p = fill(NaN, 1, 1), fill(NaN, 1, 1);

julia> calc_linear_trends_sig!(slopes, p, data, nothing, dates);

julia> round(slopes[1]; digits=3), round(p[1]; digits=4)
(1.38, 0.0112)

PlanetTools.PlanetStatistics.calc_multiyear_stats! — Method
calc_multiyear_stats!(moa, soa, w_moa, ska, kua, data, indices, kind::Val; kwargs...)

Compute weighted multi-year mean, standard deviation, and optionally skewness and excess kurtosis over the time steps selected by indices, with the fraction of valid steps as availability.

With weights w (availability × temporal weight) of the valid steps, V₁ = Σw, V₂ = Σw², the mean is μ = Σwx / V₁ and the variance

  • corrected=true (default): σ² = Σw(x - μ)² / (V₁ - V₂ / V₁), the unbiased estimator for reliability weights; with equal weights this is Σ(x - μ)² / (n - 1), the sample variance. It needs at least two valid steps (otherwise NaN).
  • corrected=false: the population variance Σw(x - μ)² / V₁.

Skewness m₃ / m₂^{3/2} and excess kurtosis m₄ / m₂² - 3 are always computed from the population central moments mₖ = Σw(x - μ)ᵏ / V₁.

  • Val(:annual): data is (Sim, Var, …, Time), outputs are (Sim, Var, …), and indices is a (Sim, 2) matrix of the first and last time index.
  • Val(:monthly): data is (Sim, Var, …, Time), outputs are (Sim, Var, …, 12), and indices is a (Sim, 12) matrix of time-index vectors, one per calendar month.
  • Val(:seasonal): data is (Sim, Var, Season, …, Year), outputs are (Sim, Var, Season, …), and indices is a (Sim, Season, 2) array of the first and last year.

Simulations (or months, seasons) with empty or zero indices are skipped.

Arguments

  • moa, soa, w_moa: outputs for mean, standard deviation, and availability.
  • ska, kua: outputs for skewness and excess kurtosis, or nothing.
  • data::AbstractArray: input, see above.
  • indices: selected time steps, see above.
  • kind::Val: Val(:annual), Val(:monthly), or Val(:seasonal).

Keywords

  • weights=nothing: (Sim, Time) (or (Sim, Year)) matrix of temporal weights.
  • data_w=nothing: availability weights, same size as data.
  • threshold::Real=100.0: minimum percentage of valid time steps.
  • corrected::Bool=true: sample (true) or population (false) standard deviation.

Examples

julia> data = reshape([1.0, 2.0, 3.0, NaN], 1, 1, 4);  # (Sim, Var, Time)

julia> moa, soa, w = fill(NaN, 1, 1), fill(NaN, 1, 1), fill(NaN, 1, 1);

julia> calc_multiyear_stats!(moa, soa, w, nothing, nothing, data, [1 4], Val(:annual);
           threshold=50);

julia> moa[1], soa[1], w[1]  # Sample standard deviation of [1, 2, 3].
(2.0, 1.0, 0.75)

julia> calc_multiyear_stats!(moa, soa, w, nothing, nothing, data, [1 4], Val(:annual);
           threshold=50, corrected=false);

julia> soa[1] ≈ sqrt(2 / 3)  # Population standard deviation.
true

PlanetTools.PlanetStatistics.calc_planet_means! — Method
calc_planet_means!(
    data, zm_out, gm_out, weights_zm, weights_gm, axyp, t_ranges; kwargs...
) -> Nothing

Compute zonal means and area-weighted global means of data and the availability of valid data for each.

The zonal mean averages over longitude (dimension 3) with equal weights; its availability is the fraction of valid longitudes. The global mean averages over longitude and latitude (dimensions 3 and 4) weighted by the cell areas axyp; its availability is the fraction of the area with valid data.

Arguments

  • data::AbstractArray: (Sim, Var, Lon, Lat, [Lev], Time).
  • zm_out, weights_zm: outputs, (Sim, Var, 1, Lat, [Lev], Time).
  • gm_out, weights_gm: outputs, (Sim, Var, 1, 1, [Lev], Time).
  • axyp::AbstractMatrix: cell areas, (Lon, Lat).
  • t_ranges::AbstractVector{<:Integer}: number of time steps of each simulation; steps 1:t_ranges[ns] are processed.

Keywords

  • threshold::Real=100.0: minimum valid percentage (of longitudes or area).
  • run_names=nothing: simulation names for log messages.
  • verbose::Bool=false: log progress with @info.

Examples

julia> data = reshape([1.0, 3.0, 2.0, NaN], 1, 1, 2, 2, 1);  # 2 lon × 2 lat

julia> axyp = [1.0 3.0; 1.0 3.0];  # Second latitude has 3× larger cells.

julia> zm, wz = fill(NaN, 1, 1, 1, 2, 1), fill(NaN, 1, 1, 1, 2, 1);

julia> gm, wg = fill(NaN, 1, 1, 1, 1, 1), fill(NaN, 1, 1, 1, 1, 1);

julia> calc_planet_means!(data, zm, gm, wz, wg, axyp, [1]; threshold=0);

julia> vec(zm), vec(wz), gm[1], wg[1]
([2.0, 2.0], [1.0, 0.5], 2.0, 0.625)

PlanetTools.PlanetStatistics.calc_seasonal_mean_ts! — Method
calc_seasonal_mean_ts!(
    data, zm, gm, out_ij, out_zm, out_gm, w_out_ij, w_out_zm, w_out_gm,
    ind_seas_first, dates; kwargs...
) -> Nothing

Compute weighted seasonal means of monthly grid-point, zonal-mean, and global-mean time series, with the fraction of valid months per season as availability.

Season ne of year ny of simulation ns averages the length_of_season time steps starting at ind_seas_first[ns, ne, ny]; an index of 0 ends that season's years.

Arguments

  • data, zm, gm: monthly inputs, (Sim, Var, Lon, Lat, [Lev], Time) and the zonal and global reductions thereof.
  • out_ij, out_zm, out_gm: seasonal means, (Sim, Var, Season, …, Year) with the spatial dimensions of the inputs.
  • w_out_ij, w_out_zm, w_out_gm: seasonal availability, same shapes.
  • ind_seas_first::AbstractArray{<:Integer,3}: (Sim, Season, Year) index of the first month of each season in Time.
  • dates::AbstractVector{<:Date}: dates of the Time dimension.

Keywords

  • data_w=nothing, zm_w=nothing, gm_w=nothing: availability weights of the inputs.
  • month_weights=nothing: weights along Time, e.g. days per month; default equal.
  • length_of_season::Integer=3: months per season.
  • threshold::Real=100.0: minimum percentage of valid months per season.
  • run_names=nothing, verbose::Bool=false: progress logging.
