PlanetTools.StatisticUtils — Module
PlanetTools.StatisticUtils

Submodule of PlanetTools with weighted statistics of gridded fields (mean, standard deviation, pattern correlation), Fisher z-transform and correlation significance, and latitude weights. Load it with using PlanetTools.StatisticUtils.

The weighted functions take arrays of any rank and reduce over dims (: for all dimensions, an integer, or a tuple). Weights must be broadcast-compatible with the data, e.g. (1, nlat) latitude weights for (nlon, nlat, …) data. Points with NaN or missing data or with weights ≤ 0 are ignored. Sums are accumulated in at least Float64.

PlanetTools.StatisticUtils.calc_correlation_significance — Method
calc_correlation_significance(r, n_eff) -> (p_value, z_score)

Return the two-sided p-value and z-score of correlation coefficient(s) r against zero correlation, from the Fisher z-transform with standard error 1 / sqrt(n_eff - 3) [Fisher, 1921]: z_score = atanh(r) sqrt(n_eff - 3), p_value = erfc(|z_score| / √2).

Arguments

  • r: correlation coefficient (Real) or array of them.
  • n_eff::Real: effective number of independent samples, > 3; for spatial fields usually much smaller than the number of grid cells.

Returns

  • Tuple: (p_value, z_score), scalars or arrays like r.

Throws

  • ArgumentError: if n_eff ≤ 3.

References

  • Fisher, R. A. (1921), On the "probable error" of a coefficient of correlation deduced from a small sample, Metron, 1, 3–32. No DOI.

Examples

julia> p, z = calc_correlation_significance(0.5, 30);

julia> round(z; digits=3), round(p; digits=5)
(2.854, 0.00431)

PlanetTools.StatisticUtils.calc_latitude_weights — Method
calc_latitude_weights(lat)

Return area weights cos(lat) for latitudes lat in degrees, normalized to sum 1 and clipped at 0 beyond the poles. They are proportional to the cell areas of a regular grid with cell-centered latitudes; for other grids (e.g. half-size polar cells), use the cell areas instead.

Arguments

  • lat::AbstractVector{<:Real}: latitudes in degrees.

Returns

  • Vector: normalized weights in the floating-point type of lat.

Examples

julia> calc_latitude_weights([-60, 0, 60])
3-element Vector{Float64}:
 0.25
 0.5
 0.25

PlanetTools.StatisticUtils.calc_weighted_mean — Method
calc_weighted_mean(vals, weights; dims=:)

Return the weighted mean Σ w x / Σ w of vals over dims, ignoring invalid points.

Arguments

  • vals::AbstractArray{<:Union{Real,Missing}}: data of any rank.
  • weights: weights broadcast-compatible with vals (an array or a Real).

Keywords

  • dims=:: dimensions to reduce; : returns a scalar.

Returns

  • The mean (an array with reduced dimensions of size 1, or a scalar for dims=:) in the floating-point type of the inputs; NaN where no point is valid.

See also calc_weighted_std, calc_weighted_pattern_corr.

Examples

julia> x = [1.0 2.0; NaN 4.0];  # (lon, lat)

julia> w = [1.0 3.0];  # Latitude weights, shape (1, lat).

julia> calc_weighted_mean(x, w) ≈ (1 * 1 + 2 * 3 + 4 * 3) / 7
true

julia> calc_weighted_mean(x, w; dims=1)
1×2 Matrix{Float64}:
 1.0  3.0

PlanetTools.StatisticUtils.calc_weighted_pattern_corr — Method
calc_weighted_pattern_corr(vals1, vals2, weights; dims=:)

Return the centered weighted pattern correlation (Pearson's r) of vals1 and vals2 over dims, Σ w (x - μx)(y - μy) / sqrt(Σ w (x - μx)² Σ w (y - μy)²). Only points valid in both fields are used, also for the means.

Arguments

  • vals1, vals2::AbstractArray{<:Union{Real,Missing}}: fields of the same size.
  • weights: weights broadcast-compatible with the fields (an array or a Real).

Keywords

  • dims=:: dimensions to reduce; : returns a scalar.

Returns

  • The correlation in [-1, 1], shaped as for calc_weighted_mean; NaN where a field has zero variance or no point is valid.

See also calc_correlation_significance.

Examples

julia> x = [1.0, 2.0, 3.0, 4.0];

julia> calc_weighted_pattern_corr(x, [2.0, 4.0, 6.0, NaN], ones(4))
1.0

julia> calc_weighted_pattern_corr(x, [1.0, 3.0, 2.0, 4.0], [1, 1, 1, 1])
0.8

PlanetTools.StatisticUtils.calc_weighted_std — Method
calc_weighted_std(vals, weights; dims=:)

Return the weighted standard deviation of vals over dims for reliability weights, sqrt(V₁ Σ w (x - μ)² / (V₁² - V₂)) with V₁ = Σ w and V₂ = Σ w², ignoring invalid points. For equal weights this is the usual sample standard deviation (n - 1).

Arguments

  • vals::AbstractArray{<:Union{Real,Missing}}: data of any rank.
  • weights: weights broadcast-compatible with vals (an array or a Real).

Keywords

  • dims=:: dimensions to reduce; : returns a scalar.

Returns

  • The standard deviation, shaped as for calc_weighted_mean; NaN where fewer than two points are valid (V₁² ≤ V₂).

Examples

julia> calc_weighted_std([1.0, 2.0, 3.0, NaN], ones(4))
1.0
