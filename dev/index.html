PlanetTools

Tools for post-processing and analyzing output of the climate models GISS ModelE and ROCKE-3D, for Earth and other planets. The functions are organized in submodules and all exported by PlanetTools, so using PlanetTools makes them available; to load only some, use a submodule, e.g. using PlanetTools.StatisticUtils.

Submodules

  • Constructors: ModelE output file names and discrete color palettes.
  • DerivePhysicsVariablesModelE: sums, differences, and quotients of variables, and cumulative dust size classes.
  • PlanetAerosolUtils: effective radius of binned size distributions and log-log interpolation of optical lookup tables.
  • PlanetDustUtils: size distribution of emitted dust from brittle fragmentation theory.
  • PlanetStatistics: spatial means, time series, multi-year statistics, anomalies, trends, and ensemble statistics.
  • PlottingTools: isolines of fields with missing data.
  • ReadWritePlanet: NetCDF input and output.
  • StatisticUtils: weighted statistics of gridded fields, correlation significance, and latitude weights.

compose_palette and finite_contour! are defined in a package extension and require Makie to be loaded (using Makie, using CairoMakie, …).

Examples

julia> using PlanetTools.Constructors

julia> fnames_modele(2010, 12, 2011, 1, "aij", ["E1"])
1×2 Matrix{String}:
 "DEC2010.aijE1.nc"  "JAN2011.aijE1.nc"

Installation

using Pkg
Pkg.add(url="https://github.com/caprrepos/PlanetTools.jl")

PlanetTools requires Julia 1.13 or later. The plotting methods compose_palette and finite_contour! additionally require Makie or one of its backends, e.g. Pkg.add("CairoMakie").
